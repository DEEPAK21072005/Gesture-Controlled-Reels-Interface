# ✋ Gesture-Controlled Reels Interface

Control Instagram Reels (or similar scrolling interfaces) using **hand gestures** powered by Computer Vision.

## 🔥 Features
- Real-time hand tracking using **MediaPipe**
- Gesture recognition (open palm, fist, thumbs up)
- Linked gestures to actions:
  - 👊 Fist → Scroll Up
  - ✋ Open Palm → Scroll Down
  - 👍 Thumbs Up → Like Post
  - 👈👉 Swipe Left/Right → Navigate
- Browser automation with **PyAutoGUI**

## 🛠️ Tech Stack
- Python 3.10
- MediaPipe
- OpenCV
- PyAutoGUI
